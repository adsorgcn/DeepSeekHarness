给作者（准入）

四条门，逐条过。

  • 清单仓库里一个以 ::ILANG::v5.0 开头的围栏，含 ::GENE{。
  • 校验器tools/ilang_grammar_validator.py --lint --strict，0 错 0 警告且 linted 不小于 1。
  • 钉死技能记清单 sha256，bundle 记 40 位 commit 与精确版本。
  • 许可仓库里有 OSI 许可文件。

三类不收：与官方能力重复；要拿走钥匙或记忆；娱乐与不稳定。来源：docs/社区插件甄选.md 第六条。

自检命令：python -X utf8 tools/market_admit.py <你的仓库 https 地址> <tag 或 commit> 通过后，到 市场准入申请 提一个 issue。维护者看过准入输出后决定收不收。
