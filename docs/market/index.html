官方插件（从 npm 装）

第一个官方插件：自媒体出海。

dsh-plugin-chuhai
说一句「自媒体出海」，从零一直带到 X 开蓝 V；前半段的书随插件带着，不装工具包也能用
说一句「自媒体出海」 · 0.2.3 · ilang · MIT · https://github.com/adsorgcn/dsh-plugin-chuhai · npm · 版本 0.2.3 · intx1EAIHeOkDW1 · Release v0.2.3

装工具包的那句话会顺手把它装上。手动装：DSH 侧栏「插件」→「添加插件」，只填包名，别把下面那条地址填进这个框： dsh-plugin-chuhai 想从列表里装：先在「插件」页的「实验性插件」下启用「自定义插件索引」，页面会多出「发现」页签，在里面点「添加索引源」贴这条地址，再在列表里点安装： https://dsh.ilang.guide/market/index.json 目前进度：到 X 开蓝 V，更新中。

别处的好东西

看见不错的技能或插件，告诉你的 DSH。

说一句是哪个，它帮你写一版更好的，照 iLang 母版写成一本工程书。写好了可以提交给我们审；过了门、owner 说收，就内置进工具包。

没有合作的第三方，我们只给作者的仓库地址，怎么用问你自己的 DSH。名单看 社区插件甄选 这一页。

给作者（准入）

四条门，逐条过。

  • 清单工程书的第一行和最后一行都是 ::ILANG::v5.0::ENGINEERING_BOOK；技能是一个以 ::ILANG::v5.0 开头、含 ::GENE{ 的围栏。
  • 校验器tools/ilang_grammar_validator.py --lint --strict，0 错 0 警告。
  • 钉死记工程书或清单的 sha256；来自别的仓库的再记 40 位 commit。
  • 许可仓库里有 OSI 许可文件。

三类不收：与官方能力重复；要拿走钥匙或记忆；娱乐与不稳定。来源：docs/社区插件甄选.md 第六条。

自检命令：python -X utf8 tools/market_admit.py <你的仓库 https 地址> <tag 或 commit> 通过后，到 市场准入申请 提一个 issue。维护者看过准入输出后决定收不收。收了的，原样内置进工具包。
