安装官方插件

安装工具包时，DSH 会询问是否安装「自媒体出海」，经你确认后才会安装。也可以在 DSH 侧栏自行添加插件。

按包名安装
打开「插件」里的「添加插件」，填入 dsh-plugin-chuhai 或 adspilot 后确认安装。
从插件目录安装
在「插件」的「实验性插件」下启用「自定义插件索引」，进入「发现」，点「添加索引源」，粘贴下方地址后选择要安装的插件。https://dsh.ilang.guide/market/index.json
自媒体出海插件目前做到哪一步？

前半段工程书随插件提供，可单独使用。目前已带到把第一本书交给 Grok Bot，再为它接上邮箱、Gmail、InstaBox、Muse、Railway、家宽 IP 和 YouTube 频道。工具包里的「出片」「云端分身」「一稿多发」三句口令均可使用，后续环节仍在更新。

收录规则

收录顺序就是显示顺序。维护者看过准入输出后决定收不收。

提交准入申请

提交前对照四项要求

清单
工程书使用 ::ILANG::v5.0::ENGINEERING_BOOK 标记首尾两行。技能清单使用以 ::ILANG::v5.0 开头且含 ::GENE{ 的围栏。
校验
运行 tools/ilang_grammar_validator.py --lint --strict，结果须为 0 错误、0 警告。
版本
记录工程书或清单的 SHA-256，外部仓库再附 40 位提交哈希。npm 插件固定包版本、integrity、发包提交和对应标签。
许可
仓库中须包含 OSI 认可的开源许可文件。

按社区甄选规则，与官方能力重复、索取钥匙或记忆，以及娱乐类或运行不稳定的条目均不予收录。

运行准入自检

在工具包仓库根目录运行相应命令，把输出附在申请里。

工程书python -X utf8 tools/market_admit.py <仓库 HTTPS 地址> <tag 或 commit>npm 插件python -X utf8 tools/market_admit.py --plugin <包名>@<版本>
发现了值得收录的第三方工具？

把想借鉴的技能或插件告诉 DSH，它可以帮你写一版更好的，并按 iLang 母版整理成工程书，完成后即可提交审阅。在社区插件甄选中可以查到第三方项目的作者仓库。
