# 社区插件甄选

## 收录规则 v1

一、只给官方信息：它是什么照官方原话（可附直译并标明），作者、许可、官方入口（仓库、官网、官方 MCP）。
二、一律标「可选」，装不装用户自己定；本仓库不分新手老手。
三、不写装法、验法、用法、例句、提需求模板；用法问自己的 DSH 或看官方文档。
四、署名给原作者不给转发者，三处登记（docs/CITATIONS.md、CITATION.cff、.zenodo.json）。
五、与收录对象无任何利益往来，责任在原作者与用户自己的选择。
六、不收三类：与官方能力重复（比如第三方识图——本仓库已有官方子代理路由，图不出本机）；要拿走钥匙或记忆；娱乐与不稳定。
