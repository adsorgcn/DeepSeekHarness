# 社区插件甄选

本仓库对社区第三方产品的吸收规矩（v1.0.31 起）：**装前问、只走官方源、署名原作者、新手不需要的不收**。
这里只放我们实测或认过的；不在这里的，一律不背书。

## 收录

### 1. REA —— 逆向学习工具

- 作者与出处：[morluto/rea](https://github.com/morluto/rea)（MIT）
- 是什么：给 coding agent 一套逆向分析工具（读汇编、解包、抓浏览器运行时），官网的例句是学「怎么把需求说清楚」的好教材
- 装法：免费全家桶可选条目 `rea`，装前问你、失败即停（需要 Node.js）
- 适合谁：开发者、想学逆向的人；**新手不必装**——去看它的官网例句学表达就够了
- 怎么用（任务表达三件套，范式来自 REA 官网）：
  > 模糊：「帮我看看这个游戏。」
  > 清楚：「查 `index.js` 里恐龙的加速规则，把规则复现成带速度滑杆的小游戏。」
- 署名：docs/CITATIONS.md、CITATION.cff、.zenodo.json 三处已列

## 不收的（原则）

社区里其余插件一概不收，原因三类，不逐一点名：

1. **与官方能力重复**：比如第三方识图插件——本仓库 v1.0.26 起用官方子代理模型选择实现「看截图→Flash 子代理」，图不出本机；再装第三方等于把图发给别人。
2. **要拿走你的钥匙或记忆**：查余额、压上下文这类，要么 API key 交第三方，要么压缩上下文可能吞掉记忆语义——新手不开这个口。
3. **娱乐与不稳定**：皮肤、桌宠、表情包、整活类不背书；作者自测都报错的更不收。

想自己探索社区插件：DSH 插件页官方有「发现」功能（实验性），装前看清来源，只装真用得上的。
