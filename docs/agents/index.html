iLang DSH 工具包

让你的 Agent，
直接找到该怎么用。

准备安装工具包时，让 Agent 先读取官方安装说明；需要某项能力时，再查技能市场。默认入口公开只读，无需密钥。

MCP 接入

在支持远程 MCP 的客户端中添加以下地址，传输方式选择 Streamable HTTP，认证方式选择「无」，无需注册账户或申请令牌。

https://dsh.ilang.guide/mcp

也可使用客户端支持的 JSON 配置格式：

{
  "mcpServers": {
    "ilang-dsh": {
      "url": "https://dsh.ilang.guide/mcp"
    }
  }
}

连接成功后，先让 Agent：「读取 iLang DSH 的 Windows 安装说明，告诉我下一步需要确认什么。」工具返回指引；安装由你的本地 Agent 按你的确认执行。

工具得到什么
dsh_overview产品说明、官方入口与可读文档清单
dsh_install_instructions按 Windows、macOS 或 Linux 返回安装指引与脚本来源
dsh_search_docs按关键词检索公开文档，返回匹配片段和来源
dsh_get_document读取白名单中的一篇公开文档
dsh_list_skills技能、工程书和插件的市场记录、版本与来源

新工作流，也能直接查

让 Agent 先检索「变工程书」「出片」或「云端分身」，再读取对应的公开原文。通过 dsh_get_document 传入以下路径，也可直接读取：

  • 变工程书：.dsh/skills/source-book/SKILL.md。把攻略、链接或截图整理成工程书，写好后再按你的指令执行。
  • 出片：.dsh/books/chupian/BOOK.md。把出片书交给已配置的 Grok Bot 或 Muse，由你审阅样片与成品。
  • 云端分身：.dsh/books/fenshen/BOOK.md。电脑与 Grok Bot 共用你的私有仓库，配置完成后用手机接续工作。
  • SEM 与付费投流（AdsPilot）：.dsh/books/adspilot-sem/BOOK.md。在你自己的账号和机器上跑通合规的 SEM 联盟投放，默认 dry-run，KYC、付款、申诉由你自己完成。
  • 一稿多发：.dsh/books/yigaoduofa/BOOK.md。一篇稿照每个平台的卡改成该平台的版本，你点头进队列，到点由手发出去；执行正文 bot-yigaoduofa-book.md。
  • 爆文公式：.dsh/books/baowen/BOOK.md。专家写完稿之后的节奏自查：标题要素、字数、金额、问句、段长、禁词与合规；合规和专家的结构压在公式上面。
  • 安装指令全文：docs/install.md。用户贴的那一句指向这页，Agent 照这页装工具包：先确认创造模式，只检测，缺什么一样一样问，官方源装。

入口卡引用的随包正文也可读取：变工程书母版（解压并核验原始 SHA256）、出片执行正文与云端分身执行正文。出片的两份原书和来源记录也在目录内。将链接的路径传给 dsh_get_document 即可；完整目录由 dsh_overview 返回。

这些工具返回使用资料；制作、同步和发布由你的 Agent 按实际配置与授权执行，公开 MCP 不会访问私有仓库或代你操作账户。

不通过 MCP，也能读取

  • HTTP API 规范：供支持 OpenAPI 的工具调用。
  • Agent 导航与文本说明：适合直接读取网页资料的 Agent。
  • Agent Skills 索引：安装规划、资料检索与市场查阅的操作说明。
  • 访问说明：当前服务无需注册、登录或令牌；未来认证声明明确标为未启用。

在支持 WebMCP 的浏览器中，首页还提供「读取安装说明」和「搜索技能市场」工具。浏览器未提供该 API 时，网页照常使用。
